# update() and remove() silently ignore document IDs given as strings

My document IDs come from a web form / JSON request, so they arrive as strings. `get()` and `contains()` are happy with that, but `update()` and `remove()` just do nothing, without any error:

```python
from tinydb import TinyDB
from tinydb.storages import MemoryStorage

db = TinyDB(storage=MemoryStorage)
db.insert_multiple([{'a': 1}, {'a': 2}, {'a': 3}])

db.get(doc_ids=['1', '2'])          # works: [{'a': 1}, {'a': 2}]
db.contains(doc_id='2')             # True
db.update({'a': 10}, doc_ids=['1']) # returns [] and nothing is updated
db.remove(doc_ids=['3'])            # returns [] and nothing is removed
```

This took me a while to find because nothing fails. I think `update()` and `remove()` should accept string IDs the same way `get()` does (and return the IDs as ints like they normally do). IDs that don't exist should still just be skipped like today.
