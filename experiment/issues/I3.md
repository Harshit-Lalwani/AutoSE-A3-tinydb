# Feature request: Query().field.between(low, high)

Range queries come up all the time for me (ages, prices, timestamps). Right now I write

```python
db.search((Query().age >= 18) & (Query().age <= 65))
```

which is fine but noisy, and easy to get wrong when the field path is long. It would be nice to have

```python
db.search(Query().age.between(18, 65))
```

with both ends included, like SQL's BETWEEN. Documents that don't have the field should just not match, the same as with `<` / `>=` today. And it should of course work with the query cache and with `&`, `|`, `~` like the other query methods.
