<!-- issue -->
I keep tags as a list in my documents. To add a tag I currently do a `get`, change the list in Python, and `update` it back, which is clumsy and not great when several documents match.

It would be nice to have an operation in `tinydb.operations` next to `add`, `increment` etc.:

```python
from tinydb.operations import append

db.update(append('tags', 'urgent'), Query().project == 'x')
```

If a matching document doesn't have the field yet, I'd like it to be created as a list with just that value. If the field exists but isn't a list, raising a `TypeError` seems right to me (like adding a str to an int does), rather than silently doing something weird.
<!-- /issue -->

## Implementation notes

Adds `operations.append(field, value)`: creates the list if the field is missing, appends otherwise, and raises `TypeError` for non-list fields, as requested. While there I made `delete()` consistent with the new operation by tolerating missing fields (it used to raise `KeyError`, which aborts the whole update). Tests added; full suite passes.
