# ADR-014: Agents see only their last four tool exchanges in full

**Date:** 2026-11-24 · **Status:** Accepted · **Decision area:** D4 State / D9 Cost (result of experiment E2)

## Context
The tool loop sent the whole conversation on every call, so the prompt grew with every step and the
total cost grew roughly with the square of the number of steps. In the default-variant runs on the
ADR-013 code, a coder call reached 35–43 k prompt tokens; one coder agent spent 968 k tokens in 41
calls, another 2.15 M in 82 calls (two attempts). Six of six default runs on issues #1, #2, #4, #5
stopped with "token budget exhausted" (ADR-012, 2.5 M per run) in the implement/test loop, while the
single-agent variant (E2) reached a PR on #1 and #4 with 274–417 k tokens. Measured in the logs, about
55 % of the context was old tool output and about 40 % old tool-call arguments (whole files passed to
`write_file`, heredocs).

## Decision
Before every model call, tool outputs and tool-call arguments older than the last four tool exchanges
are cut to their first 200–300 characters with a marker telling the agent to re-run the command if it
needs the output again (`compact` in `agent.py`). Arguments stay valid JSON (long string values are
shortened, keys kept). System prompt, task, the agent's own text and the last four exchanges are
untouched. Budgets (ADR-012) and the default split (ADR-001) are unchanged.

## Alternatives considered
- **Raise the run budget.** Treats the symptom; cost would still grow quadratically with steps.
- **Switch the default to the single-agent variant.** E2 says it is cheaper, but on these issues the
  default failed for cost reasons, not because separate testing is wrong; we first remove the cost
  problem and re-measure.
- **Summarise old steps with an LLM call.** Keeps more meaning, but costs a call and adds an unverified
  summary to the context.

## Consequences
- Per-call prompt size is roughly bounded instead of growing with steps.
- An agent that needs an old output must re-run the command (cheap here: the commands are local).
- Provider-side prompt caching hits less often, because older messages change; on free tiers this does
  not cost money, and the budget counts raw tokens anyway.
- Runs before this ADR and after it are not directly comparable; `results.csv` records the workflow
  commit of each run.
